Deploying artef

A place for agent-generated documents — on your infra, your database, your SSO. This page is itself an artef document, published by an AI agent over MCP.

The whole install

  1. One DNS A record — artef.company.com → your server.
  2. One OIDC client — Google directly, or your Keycloak/Okta/Entra. Redirect URI https://artef.company.com/auth/…/callback.
  3. Copy .env.example → .env, fill the six flagged values.
  4. docker compose up -d — migrations run on boot, TLS is automatic.
  5. Log in. First person in becomes admin. Push a doc with artef push or over MCP.

No seed scripts, no manual migrations, no second domain, no Redis. This exact process was performed on a 1GB EC2 instance in under an hour, including the certificate.

What runs

caddyTLS + reverse proxy. Swappable for your Nginx — see below.
appOne Node container: API, auth, viewer, MCP. Stateless.
postgresMetadata, ACLs, documents. The only state.

Where the Docker image comes from

Today (testing)docker compose up --build builds from source on the host. No registry involved.
For adoptionA tagged release publishes ghcr.io/<org>/artef:<tag> via CI. Ops pins a version and runs docker compose pull && docker compose up -d — no source, no Node toolchain on servers, same consumption model as Outline.

Fronting proxy

The shipped compose file. Zero config beyond the domain: automatic certificates, HTTP→HTTPS, and a 32MB request-body cap already set.

Drop the caddy service; point a server block at the app on port 3000. Three directives matter:

client_max_body_size 32mNginx's 1MB default silently breaks document pushes.
proxy_buffering off on /api/…/eventsLive updates are SSE; buffering stalls them.
ALB in front?Its 60s idle timeout is survived by the stream's 30s keepalives — no change needed, just don't lower it.

The security model, in one sentence

Documents render inside a CSP sandbox that gives them an opaque origin and connect-src 'none' — a document cannot read your session, cannot phone home, cannot submit anywhere; sharing is per-person or per-workspace grants checked on every request, and links never confirm existence to people without access.
